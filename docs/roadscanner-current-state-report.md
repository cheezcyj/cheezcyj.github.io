## 반영 범위

- 전체 도로 장면의 표지판 후보 검출과 GTSRB 43종 분류
- 신뢰도, 분류 간격과 OOD 기준을 이용한 `인식 불가` 처리
- 공개 Q&A, 비공개 문의와 회원·관리자 기능
- 인증·권한·입력·이미지·외부 요청 검증을 포함한 보안 처리
- Java 및 Python 테스트와 로컬 통합 실행 구성
